# Довідники для сідерів

`localities.json` – міста та селища України за областями (2395 записів).
Джерело: Кодифікатор адміністративно-територіальних одиниць та територій територіальних громад (КАТОТТГ)
станом на 19.01.2024, у вигляді npm-пакета [ua-geo-set](https://github.com/0G3RA/ua-geo-set) (ліцензія MIT).
Взято категорії «міста» (M) і «селища» (X); села (≈28 тис.) свідомо не включено, щоб список у формі
лишався зручним. Київ додано окремо як місто зі спеціальним статусом.
