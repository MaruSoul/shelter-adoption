# Протоколи перевірок

Реліз: тег `v1.0.0` (див. `git show v1.0.0`). Дата вимірювань: 16.11.2026.

## Середовище, на якому виміряно

| Параметр | Значення |
|---|---|
| ОС | Linux x86_64 (Ubuntu 24.04), 2 vCPU, 8 ГБ RAM – хмарна пісочниця розробки |
| Вебсервер | nginx 1.24 з конфігурацією `docker/nginx/default.conf` (gzip, кешування `/build/`) |
| PHP | php-fpm 8.3, OPcache увімкнено, `config:cache`, `route:cache`, `view:cache`, `APP_DEBUG=false` |
| СКБД | PostgreSQL 16, демо-дані сидера (40 тварин) |
| Браузер | Chrome for Testing 153 (headless) |

Відмінність від Docker-збірки: у контейнері PHP 8.5 і PostgreSQL 17. Генератор навантаження k6 працював на тій самій машині, що й сервер.
