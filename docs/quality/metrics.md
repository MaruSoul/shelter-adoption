# Метрики коду

Звіт за таблицею Д.18 методичних вказівок. Область аналізу – власний код застосунку `app/`
(для дублювання також шаблони `resources/views`). Не аналізуються: `vendor/`, `node_modules/`,
зібрані файли `public/build`, міграції й сидери (декларативні описи даних), тести.

Дата вимірювання: 22.11.2026, фінальна версія (тег `v1.2.0` і виправлення після нього). Порівняння з версією до рефакторингу – у таблиці нижче.

Додати новий тип блоку статті тепер означає створити клас, що реалізує `App\Services\Blocks\BlockType`,
зареєструвати його в `PostBlocks::BLOCKS` і додати два шаблони; наявні класи не змінюються.
Тест `BlockTypesTest` перевіряє, що кожен зареєстрований тип має шаблони, валідацію й приклад даних.
